## 解压并上传

1. 下载并解压 `spoken-script-engine_github-assets_v1.3.zip`。
2. 打开解压目录，找到直接包含 `README.md`、`KB-MANIFEST.json` 和 `rules/` 的这一层。
3. 新空仓库页面选择上传已有文件入口；已有文件列表时选择 **Add file → Upload files**。
4. 将这一层的全部文件和文件夹拖入上传区域，保留目录结构。上传内容不要再套一层外部目录；不要只上传ZIP文件。
5. 提交说明可填：`Initialize v1.3 platform rules and spoken-script assets`。提交到默认分支；如通过新分支提交，先合并后再接入。
6. 确认仓库根目录直接有 `KB-MANIFEST.json`，且 `rules/`、`platforms/`、`shared/`、`sources/`、`memory/`、`genes/` 均存在。

本包低于GitHub网页上传的100文件/次和25MiB/文件限制。根目录组织与UTF-8正文已检查；上传时保留JSONL空文件、原编码及换行，不用Excel打开并重存JSONL，也不要另存为带BOM的文本。

根目录示例：`KB-MANIFEST.json` 和 `platforms/xiaohongshu/topics.jsonl`。错误位置示例：`spoken-script-engine/KB-MANIFEST.json`。
