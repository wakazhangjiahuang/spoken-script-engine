# 口播稿引擎 3.6.1

**当前私有插件与完整Skill版本：3.6.1｜更新日期：2026-11-23**

3.6.1是在3.6.0基础上的定点闭环升级。保留既有AI视频V4.1、插画V2.0、三平台知识库、双标杆、样例、原始工作簿和历史兼容；重点将「理解—决策—生成—验证」转化为可执行门禁和可追溯证据。

## 3.6.1核心升级

1. **理解：原始文件→事实→口播主张。** 原始文件SHA、原文位置、source quote、Fact_ID和实际口播引用逐层绑定；非文本材料必须有提取证据。
2. **决策：至少三个不同营销入口。** 比较目标用户、真实需求、点击理由、承诺收益、证据、交付、商业价值、风险与反证；所有未选方案必须记录否决理由。
3. **生成：15项标准落到成品。** 封面、0–3秒、3–8秒、正文模式、爽点兑现、能力放大、痒点升维、Calling、证据、平台与口播都要引用实际成品。
4. **验证：独立凭证和外部证据。** 评审者与生成者身份/会话、盲审包、评审证据、批次/决策/来源SHA绑定；真人试读、逐稿目标用户盲读、授权及真实发布数据分别验收。
5. **非补偿门禁。** 每篇15项逐条验收；任何失败即BLOCKED；外部验证未完成保持VALIDATION_PENDING；平均分不能放行。
6. **唯一正式入口。** `scripts/run_pipeline_v3_6_1.py`保留v3.6.0旧门禁和AI视频/插画领域正式验证器，再追加四层证据闭环。

## 验收边界

代码测试证明执行门禁和证据绑定有效；不等于真实点击、完播、询盘或成交已验证。真人试读、目标用户盲读、权利授权和平台效果未完成时，必须保持VALIDATION_PENDING。任何内部评分、平均分或CI成功均不能替代外部证据。

## 隐私

本仓库只发布通用规则、脱敏标杆机制、schema、验证器和测试。原始用户Word/XLSX、客户资料、项目事实、原稿、影像和授权材料保留在私有插件资产中。
