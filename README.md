# 口播稿引擎 3.1.0

2026-11-20：3.1.0 是功能迭代发布。保留原有三平台口播能力与3.0.0批次数据合同，增加强制选题确认门禁、04真人视频录制版、05 H3数字人口播版与二合一导出、素材条件绑定及交付前自动校验。

## 新增能力
- Topic Gate：先识别受众、用户问题、“关我什么事”、利他回报、证据和故事推进；系统反方审查后展示选题确认板，用户确认后才生成完整稿件。
- 视频制作模式：recording（04）、h3（05）、combined（04+05）。
- 05按最终校正版37列结构输出；P01/P02/A01条件绑定；R类真实素材只后期插入；真人采访不默认数字人化。
- 回归测试覆盖Topic Gate、视频模式和H3字段/时间轴。

## AI视频样例与隐私边界
完整校正版工作簿（9条脚本、72行04、101行05）及团队Word指导手册已纳入用户私有的ChatGPT插件资产包。当前GitHub仓库实际可见性为Public，而注册表的目标可见性为Private；因此本公开仓库只保存脱敏样例索引、结构说明和通用规则，不复制未脱敏原件。需要先解决仓库可见性不一致，再考虑把原件同步到GitHub。

程序回归通过只证明合同和结构，不证明真实H3画面质量、真人试读或平台传播效果。未执行的实测继续标记NOT_RUN。
