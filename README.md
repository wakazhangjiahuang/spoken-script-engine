2026-11-20：3.1.1 定向质量升级。保留原有三平台口播能力和 3.0.0 批次数据合同；补强选题确认、表达兑现审查、AI视频制作模式、素材资产分层与交付前校验。

## 本次重点
- Topic Gate 1.1：先识别具体受众、当前处境、用户问题、“关我什么事”、利他回报、故事推进和证据，再交付选题确认板；用户确认后才生成完整稿件。
- Expression Contract：独立审查封面主标题、副标题、0–3秒开场、3–8秒承接/悬念、正文、Calling和评论钩子，要求每个字段各司其职并形成同一兑现链。
- 视频制作模式：`recording`（04真人录制）、`h3`（05 H3数字人口播）、`combined`（04+05二合一）。
- 05遵循最终校正版37列结构；P01/P02/A01按需绑定；R类真实素材后期插入；真人采访不默认数字人化。
- 公开样例库增加经过编辑校正的正向示范和负面拦截模式。原始工作簿与Word指导手册保留在私有插件资产包，不发布未脱敏原件。

## 表达质量特别约束
选题理解正确不等于表达合格。标题不能只是作者事件或工具名；开场不能复读封面；3–8秒必须增加新信息和继续观看理由；Calling只能有一个主要动作，不能把内部字段名念给观众；评论钩子与Calling同目的但不机械重复。没有真实计时、测试或授权证据，不得承诺“几分钟”“零门槛”“小白都会”或效果提升。

## 验证边界
程序回归通过只证明字段合同、引用和静态规则；不证明真实H3生成质量、真人试读、成片播放、平台点击或商业转化。未执行的实测继续标记 `NOT_RUN`。
