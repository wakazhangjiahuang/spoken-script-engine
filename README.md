# 口播稿引擎 3.3.0

**当前私有插件包：3.3.0｜更新日期：2026-11-23**

3.3.0的重点不是增加更多规则，而是让当前规则真正进入执行路径：固定GitHub commit检索、私有资产SHA校验、来源冲突裁决、BENCHMARK/DERIVED_SCRIPT身份隔离、独立内容审查与事实审查、非补偿性硬门禁、领域专用导出和工作簿回读。

## 发布结构
- 基础包：`releases/3.1.1/`
- 历史补丁：`releases/3.1.3/`
- V4.1决策与QA覆盖层：`releases/3.2.0/`
- AI视频样例与检索治理覆盖层：`releases/3.2.1/`
- 当前运行质量与插画V2.0覆盖层：`releases/3.3.0/`

## 3.3.0新增
- 插画BENCHMARK只做正向机制拆解，不评分、不诊断、不改写。
- 插画六表合同：18篇、三平台各6篇、72个只读锁定单元格、04共108段、05动态H3镜头4–15秒。
- 逐稿评分和非补偿性硬门禁；禁止批次平均分掩盖单篇失败。
- 独立盲审、事实/授权审查、真人试读、目标用户盲读分开记录。
- 公开验证器与Schema；私有原始资料不进入公开仓库。

## 版本引用
`asset_ref`固定当前3.3.0覆盖层；`manifest_ref`单独固定历史AI视频样例索引来源。两个引用不能混用。

## 隐私与验证边界
公开仓库仅保存通用规则、脱敏治理、Schema和验证器；用户原始Word/XLSX、锁定基线、客户资料、作品、原片和授权文件保留在私有插件资产。CI通过只证明结构和自动化合同检查通过，不证明真人口播、目标用户点击、平台表现或商业转化。未执行的验证必须标记`NOT_RUN`/`VALIDATION_PENDING`。
