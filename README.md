## 3.6.0核心修复
1. 两类正向标杆分域治理：商业插画案例与AI视频营销方法参考只迁移机制，不复制原句、不跨域、不自动作为few-shot或评分对象。
2. Intake先完成source_inventory；默认优先相关真实用户项目，真实案例不得无理由替换成模拟。模拟需要授权及口播披露。
3. 每条计划选择真实商业案例、AI工作流教程、设计决策分析、商业机会分析或获授权模拟场景之一，不再强制统一A/B前后对比叙事。
4. 独立营销评审逐篇引用实际台词，检查用户相关性、点击链路、前8秒新增信息、承诺兑现、能力放大、痒点升维和来源保真。
5. 新增run_pipeline_v3_6.py唯一入口，保留v3.5.0内容兑现门禁及v3.5.1 AI视频V4.1正式验证器。

本仓库只发布通用规则、脱敏标杆机制、schema、验证器与测试。原始用户Word/XLSX、客户资料、项目事实、原稿、影像和授权材料保留在私有插件资产中。


## 3.6.1核心修复
1. 将理解—决策—生成—验证四层落实为唯一执行入口和阶段门禁，原始文件SHA、精确引用、事实ID与口播主张可追溯。
2. 决策阶段至少比较三个实质不同的营销入口，保留取舍、反证和否决理由。
3. 五种内容模式分别组织叙事，15项标准逐稿绑定实际成品，任一失败即阻断，不以平均分补偿。
4. 独立评审凭证绑定评审者/生成者身份、会话、盲审包、评审证据及批次/决策/来源SHA。
5. 真人试读、目标用户盲读、授权和真实发布数据独立核验；未执行保持VALIDATION_PENDING。

自动化测试只证明契约与代码门禁有效，不证明真实平台表现。公开仓库不包含用户原始客户资料、Word/XLSX原件、插画/视频素材或授权文件。
