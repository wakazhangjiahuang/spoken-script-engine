# 口播稿引擎 3.1.3

2026-11-20：当前插件包版本 3.1.3。3.1.1 提供AI视频选题、表达和制作规则；3.1.2 对齐插件资产包与公开仓库引用；3.1.3 加强标点归一化后的表达负面模式静态检测。保留原有三平台能力与 3.0.0 口播批次数据合同。

当前插件补丁目录：`releases/3.1.3/`。
AI视频规则与公开脱敏样例：`releases/3.1.1/`。

## 能力
- Topic Gate：具体受众、当前处境、用户问题、“关我什么事”、利他回报、故事推进、证据和平台差异；确认选题后才写完整稿件。
- Expression Contract：分别校验封面主副标题、0–3秒开场、3–8秒承接/悬念、正文、Calling和评论钩子，要求形成同一兑现链。
- 视频模式：`recording`（04真人录制）、`h3`（05 H3数字人口播）、`combined`（04+05）。
- 05按最终校正版37列结构；P01/P02/A01条件绑定；R类真实素材后期插入；真人采访不默认数字人化。
- 正向样例为结构示范，负面样例用于阻止重复交付低质量表达；静态检测不能代替语义复核。

## 隐私与公开仓库
GitHub仓库已核验为 Public。公开仓库只保存脱敏规则、字段合同和编辑校正后的通用样例；完整用户工作簿与团队Word指导手册仅存于私有插件资产包，不公开上传。

## 验证边界
静态校验不能证明真实观看意愿、真人试读、H3生成质量、成片质量或平台传播效果。未执行的实测继续标记 `NOT_RUN`。
