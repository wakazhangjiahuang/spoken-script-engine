## 领域与隐私边界
AI视频A/B/C业务事实仅在AI视频任务中启用；其他领域继续使用自己的知识库。公开仓库保存用户批准公开的Markdown样例、脱敏规则、Schema和测试；原始V4.1 Word、校正版工作簿、客户资料、原片与授权材料继续保留在私有插件资产中。

## 验证边界
CI通过只证明仓库结构和自动化合同检查通过，不证明目标用户点击、真人口播自然度、实际平台表现或商业转化。未做的验证必须标记`NOT_RUN`/`VALIDATION_PENDING`。
