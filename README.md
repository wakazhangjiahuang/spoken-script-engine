# 口播稿引擎 3.2.0

2026-11-22：当前私有插件包版本 3.2.0。3.2.0 在3.1.3的三平台与04/05视频生产能力上，新增V4.1营销表达决策、候选角度竞争、Jev/Laya式评审角色、AI视频八维评分与硬门禁、逐条批量验收和Loop Learning。保留3.0.0口播批次数据合同。

当前插件补丁目录：`releases/3.2.0/`。
历史3.1.3补丁：`releases/3.1.3/`。
AI视频V4.1公开脱敏规则：`releases/3.2.0/skills/spoken-script-engine/references/`。

## 能力
- Topic Gate 1.2：具体受众、共同任务、用户语言、观看回报、三个不同营销入口竞争、反方检查和锁定字段保护。
- Expression Contract 2.0：主副标题、0–3秒、3–8秒、正文、证据、Calling与评论形成同一兑现链。
- Decision Gateway：Rule Engine、Fast Screen、Deep Review、Critic与Decision Policy；Jev/Laya是决策角色，不代表已连接对应模型API。
- AI视频专属评分：八维100分；70–74返工、75–84候选、85–100强候选；硬门禁失败时无论总分都不放行。
- 批量验收：Topic_ID与Script_ID分开计数；三平台脚本分别计数；每条独立验收，不以平均分放行。
- Loop Learning：失败归因、定点修复、正负样例回归、人工确认、版本发布与回滚。
- 视频模式：`recording`（04真人录制）、`h3`（05 H3数字人口播）、`combined`（04+05）；保留原有素材绑定和工作簿结构。

## 领域隔离
V4.1的A/B/C业务线、AI视频客户与商业主张只在AI视频任务中启用。插画、旅游、工程咨询等其他领域继续使用各自的知识库和规则，不加载AI视频行业事实。

## 隐私与公开仓库
GitHub仓库为Public。公开仓库只保存脱敏规则、Schema、程序和通用测试；原始V4.1 Word指导书、原始工作簿、客户资料、原片与授权材料仍保留在私有插件资产中，不公开上传。

## 验证边界
静态/合同测试不能证明真实观看意愿、目标用户理解、发布流量或商业转化。未执行的真人朗读、用户盲测、独立模型审查和发布测试必须标记NOT_RUN/VALIDATION_PENDING。相同模型分角色不等于独立模型验证。
