# 口播稿引擎 3.5.0

**当前私有插件包：3.5.0｜更新日期：2026-11-23**

3.5.0不重建已确认的目标受众、核心需求或选题库，而是在AI视频V4.1、插画V2.0和Title Guide V4之上，修复“知道标准却无法交付合格内容”的执行断点。

## 发布结构
- 基础包：`releases/3.1.1/`
- 历史补丁：`releases/3.1.3/`
- V4.1决策与QA覆盖层：`releases/3.2.0/`
- AI视频样例与检索治理覆盖层：`releases/3.2.1/`
- 当前运行质量与插画V2.0覆盖层：`releases/3.3.0/`
- 内容决策与来源引用初版：`releases/3.4.0/`
- 当前源资料绑定与质量门禁：`releases/3.4.3/`
- 内容兑现与专业演示门禁：`releases/3.5.0/`

## 3.5.0核心修复
- 计划层复用现有受众和需求，绑定共同任务、why-now、点击理由、观看回报、证据计划及三个真正不同的营销入口。
- 正文层新增worked example：具体输入、判断标准、备选取舍、处理前后状态、可观察变化和可迁移规则；关键锚点必须逐字存在于正文。
- Calling新增价值交换：一个行动、行动理由和用户得到的具体奖励；纯互动请求不能代替用户价值。
- 核心营销与专业价值维度最低4/5，其他维度最低3/5；保留V4.1/V2.0原评分权重、70分最低线和80分内部目标，硬门禁不允许总分补偿。
- 新增13项私有回归测试；此前六篇低质量稿作为私有负向样例，不进入公开仓库，也不作为正向few-shot。
- 新增唯一执行入口`run_pipeline_v3_5.py`，在原有来源绑定、BENCHMARK保护、插画72格锁定和AI视频正式验证器上增加内容兑现门禁。

## 版本引用
`asset_ref`固定当前3.5.0覆盖层；`manifest_ref`单独固定AI视频样例来源；`registry_commit`固定注册表版本。三个引用不能混用。

## 隐私与验证边界
公开仓库仅保存通用规则、脱敏治理、Schema和验证器；用户原始Word/XLSX、锁定基线、客户资料、作品、原片和授权文件保留在私有插件资产。自动化测试通过不等于真人口播、目标用户点击、平台表现或商业转化已经验证。未执行的验证必须标记`NOT_RUN`/`VALIDATION_PENDING`。
