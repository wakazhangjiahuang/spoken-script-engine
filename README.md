# 口播稿引擎 3.4.3

**当前私有插件包：3.4.3｜更新日期：2026-11-23**

3.4.3不是新增一套受众或选题方法，而是把已经确认的领域指导书、受众需求和样例真正接入生成链路，并将专业判断变成可验证、可口播、可复核的交付合同。

## 发布结构
- 基础包：`releases/3.1.1/`
- 历史补丁：`releases/3.1.3/`
- V4.1决策与QA覆盖层：`releases/3.2.0/`
- AI视频样例与检索治理覆盖层：`releases/3.2.1/`
- 当前运行质量与插画V2.0覆盖层：`releases/3.3.0/`
- 内容决策与来源引用初版：`releases/3.4.0/`
- 当前源资料绑定与质量门禁：`releases/3.4.3/`

## 3.4.3核心修复
- AI视频V4.1业务指导书、当前团队制作手册全文实际进入资产包。
- 插画V2.0指导书与Cover Title Guide V4全文实际进入资产包。
- 插画历史平台current-examples从当前正向检索中排除。
- 计划与脚本绑定同一条原始需求引用：source_asset_id、source_locator、source_quote。
- 专业决策必须在口播正文中说清输入、约束、备选、取舍、理由、边界和用户动作，并逐项提供原文锚点。
- 插画评分引用定位到对应字段或镜头；每维最低3/5、加权总分不低于70，硬门禁不可被总分抵消。
- AI视频继续使用V4.1正式验证器。
- intake、plan、draft、validate、export统一走源资料感知的执行入口。

## 版本引用
`asset_ref`固定当前3.4.3覆盖层；`manifest_ref`单独固定AI视频样例来源；`registry_commit`固定注册表版本。三个引用不能混用。

## 隐私与验证边界
公开仓库仅保存通用规则、脱敏治理、Schema和验证器；用户原始Word/XLSX、锁定基线、客户资料、作品、原片和授权文件保留在私有插件资产。14项确定性单元测试通过不等于真人口播、目标用户点击、平台表现或商业转化已经验证。未执行的验证必须标记`NOT_RUN`/`VALIDATION_PENDING`。
