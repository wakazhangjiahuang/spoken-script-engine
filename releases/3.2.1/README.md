## 本次新增
- A01 V5.0：用户校准的直播回放营销结构标杆；70/100是用户校准基线，不是独立认证或已验证爆款。
- 六案例 V1.0：六个AI视频业务任务候选样例；全部尚未完成目标客户盲读、非作者真人朗读和实际发布验证。
- 样例索引与治理契约：明确benchmark/candidate身份、按任务检索、A01/S01隔离和晋升条件。
- 回归测试：检查路径存在、ID唯一、样例状态正确和A01/S01不作为同级正向样例共同调用。

## 重要校正
六案例来源文件名中的“60分”不是六条样稿的逐条评分记录。V4.1的质量门槛仍然适用：70–74返工、75–84候选、85–100强候选；硬门禁失败时不得放行。

## A01与S01关系
六案例S01与A01都涉及直播回放，但任务层级不同：
- A01：广义直播回放营销、内容资产化和营销表达方法论。
- S01：更窄的产品演示片段剪成步骤完整的教程。
同一任务中不得把两者作为两个同级正向few-shot共同使用。
