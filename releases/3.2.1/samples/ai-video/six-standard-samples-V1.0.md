# 仨藏｜AI视频营销表达方法论与六条标准样稿

**版本：V1.0**  
**用途：** 作为 `$spoken-script-engine` 的营销表达知识样例、口播脚本正向样例及人工审核参考。  
**适用业务线：** A｜AI视频剪辑；B｜AI口播稿视频；C｜AI数字人视频。  
**本轮范围：** 只精修原有六个案例，不扩展选题数量。  
**状态：** 编辑候选稿。尚未完成目标客户盲读、非作者真人朗读和实际发布数据验证，不得标记为“已验证有效”或“爆款样例”。

---

## 0. 核心结论

**营销表达不是把句子写得更夸张，而是把客户在意的结果、当前遇到的阻碍、AI视频改变的工作环节，以及客户看完能获得的价值，连成一条可理解、可兑现的链路。**

一条合格的AI视频营销内容，不能只回答“AI能做什么”，还要让目标客户理解：

1. **这件事为什么与我有关？** 对应我的哪项工作、业务任务或现实问题？
2. **AI视频具体改变了什么？** 改变哪个环节，输入什么资料，经过什么处理，最后交付什么？
3. **我为什么需要这项服务？** 专业服务带来的不只是调用工具，还包括需求判断、内容策划、资料整理、脚本、画面组织、制作、复核和交付。
4. **我凭什么相信？** 是否有真实素材、操作过程、可核验资料、前后对照或明确的适用边界？

### 一句话表达公式

> **客户想要的结果 → 当前的具体阻碍 → AI视频改变的工作环节 → 可见的交付结果 → 证据与边界 → 一个自然的下一步。**

也可以简写为：

> **客户为什么在意 → 为什么现在值得看 → AI具体怎么帮 → 看完得到什么 → 为什么可信 → 下一步做什么。**

这里的“损失”不一定是金钱损失。它可以是重复解释、资料闲置、客户理解困难、内容无法复用、培训依赖个人、产品信息难以理解等真实摩擦。没有证据时，不得把摩擦夸大成经营损失，也不得制造焦虑。

## 1. 必须掌握的知识点

### 1.1 “客户为什么点开”与“客户为什么需要AI视频服务”不是同一个问题

| 层次 | 要回答的问题 | 常见错误 | 合格表达 |
|---|---|---|---|
| 点击动机 | 为什么这件事值得我停下来？ | 只介绍作者、工具或功能 | 从客户熟悉的任务、困扰、机会或选择切入 |
| 需求理解 | 我现在的问题到底是什么？ | 只说“效率低”“内容不够” | 说清具体场景、动作、对象和阻碍 |
| 方案理解 | AI视频改变了哪个环节？ | 只说“AI赋能”“一键生成” | 说清输入资料、AI处理、人工作业和视频交付 |
| 观看回报 | 看完我能获得什么？ | 只承诺“了解AI”“提升效率” | 给出可执行的方法、判断、流程或内容样例 |
| 服务价值 | 为什么需要专业服务，而不是只用一个工具？ | 把工具功能当成服务价值 | 展示策划、内容判断、专业审核、画面组织、制作和交付的完整工作 |
| 信任依据 | 为什么相信这套做法？ | 虚构案例、夸大效率或效果 | 使用真实素材、原始资料、操作记录、授权案例和适用边界 |
| 行动承接 | 看完之后，下一步做什么？ | 泛泛要求关注、私信 | 让用户提交一个素材、描述一个任务或先做一次小范围评估 |

**判断重点：** 点击入口可以从痛点、机会、结果、反差、故事或专业认同切入；但无论选择哪种入口，正文都必须兑现它。不能为了吸引点击而制造一个正文无法回答的问题。

### 1.2 营销张力从哪里来

营销张力来自“用户想要的状态”与“当前真实状态”之间的差距，而不是来自夸张词。

| 张力来源 | 用户已有状态 | 用户希望得到的状态 | AI视频可以改变的环节 |
|---|---|---|---|
| 内容闲置 | 直播或活动录像拍完就存档 | 原始内容继续产生不同用途的视频 | 转写、筛选、主题重组、剪辑 |
| 知识难传播 | 专家发言留在长录像里 | 观点、案例和方法能被独立观看 | 主题提取、上下文整理、系列剪辑 |
| 专业难理解 | 客户只看到资质和服务清单 | 客户看懂问题处理过程 | 专业资料转口播、流程图和讲解视频 |
| 重复解释 | 客服反复回答相同标准问题 | 标准答案可重复观看 | FAQ整理、数字人讲解、版本管理 |
| 产品难选择 | 客户看到参数却不会比较 | 客户理解型号差异和使用条件 | 参数转选购问题、口播和实拍演示 |
| 经验难沉淀 | 专家讲过，团队仍需反复询问 | 经验形成可学习的岗位内容 | 会议转写、专家补充、知识结构化和培训视频 |

### 1.3 AI视频服务的植入原则

**AI不是为了出现在文案里而出现。** 只有当AI确实改变了内容生产、整理、表达或制作中的某个环节，才应该植入。

每条内容至少讲清以下四件事：

- **输入：** 原始直播、活动录像、业务资料、客服问题、产品说明、会议录音等。
- **AI处理：** 转写、初筛、分类、提炼、脚本辅助、分镜辅助、数字人生成或剪辑辅助。
- **人工责任：** 专业判断、事实核验、内容取舍、授权审查、最终验收。
- **视频交付：** 营销短视频、专家观点视频、专业讲解视频、FAQ视频、产品讲解视频或岗位培训视频。

不能只写“AI帮你生成视频”。要写出AI改变了哪个工序，以及最终视频解决了谁的什么问题。

### 1.4 专业服务为什么有价值

客户购买的不是“替他点一下AI工具”，而是能否把一项业务任务可靠地转化为合格的视频内容。

专业服务的价值可能包括：

1. 判断哪些资料适合做视频，哪些不适合；
2. 找到目标用户真正关心的表达入口；
3. 把专业资料转成用户听得懂的脚本；
4. 选择合适的真人口播、数字人、实拍、屏录、图解和剪辑方式；
5. 核对事实、专业结论、产品参数、授权和版本；
6. 按明确用途交付，而不是只交付一个“生成成功”的视频文件。

**反向检验：** 如果把“AI”两个字删掉，内容仍然只是在介绍普通宣传片或一般视频制作，说明AI视频业务价值还没有讲清楚；如果只剩工具功能，客户又看不出为什么需要专业服务，也没有打通商业表达。

## 2. 从封面到转化的表达链路

| 字段 | 必须完成的任务 | 不合格表现 |
|---|---|---|
| 封面主标题 | 让目标用户识别熟悉的任务、问题或利益入口 | 只介绍AI功能、作者背景或抽象概念 |
| 封面副标题 | 补足方法、场景、交付物或信息缺口 | 重复主标题，或只堆“AI赋能、智能、高效”等词 |
| 发布标题 | 补充搜索主题、具体场景和观看价值 | 直接复制封面，或只写作者想表达的主题 |
| 0–3秒 | 迅速唤醒目标用户的真实经历或问题 | 自我介绍、铺垫背景、复述封面 |
| 3–8秒 | 新增信息，明确AI改变的环节和预期结果 | 换词重复0–3秒，或只说“今天教你一个方法” |
| 正文 | 用步骤、选择、过程、对比和边界兑现承诺 | 只有功能清单，没有具体操作和信息增量 |
| 证据 | 让观众看到为什么可信 | 虚构客户、伪造屏录、未经授权的素材或无来源数据 |
| Calling | 只安排一个主要行动，并说明行动理由 | 泛泛关注、私信，或同时要求点赞收藏转发咨询 |
| 评论钩子 | 让目标客户容易说出自己的场景或问题 | 与主题无关的互动问题 |

### 跨字段兑现关系

- **主标题 → 副标题：** 主标题建立入口，副标题补充新信息。
- **副标题 → 0–3秒：** 开场唤醒同一个用户利益或矛盾，但不能简单复述封面。
- **0–3秒 → 3–8秒：** 第二段必须新增AI解决方式、内容结果或故事方向。
- **3–8秒 → 正文：** 正文马上开始兑现，不要先讲一大段背景。
- **正文 → Calling：** 本篇价值先交付，再提出自然的下一步。
- **Calling → 评论：** 两者服务同一个主要目标，评论问题要具体、容易回答。

**时间说明：** 0–3秒和3–8秒是本工作室的脚本策划分段，不是平台算法保证或硬性流量门槛。最终必须真人试读，不能为了字段而塞入过长台词。

## 3. 自辩自证：每条样稿生成前必须完成的内部检查

### 3.1 至少比较三个营销入口

不要拿到一个主题就直接写标题。先比较至少三个不同入口：

- **痛点入口：** 用户现在遇到什么具体阻碍？
- **结果/机会入口：** 用户希望得到什么结果，现有资源还有什么价值？
- **过程/反差入口：** 旧做法与新做法有什么可见差别？
- **专业认同入口：** 哪项专业能力、判断或知识值得学习？

再根据真实材料、目标用户相关性、可兑现程度和服务承接选择一个主入口。不是把所有入口拼在一个标题里。

### 3.2 五个反证问题

1. **用户反证：** 如果目标客户看到封面，能否不用解释就说出“这条内容与我有什么关系”？
2. **AI反证：** 如果去掉AI，方案是否仍然完全一样？如果是，AI的实际作用可能没有讲清楚。
3. **服务反证：** 客户为什么需要专业制作服务？如果一个通用工具就能完成全部工作，必须进一步解释专业服务的必要性，不能强行制造需求。
4. **证据反证：** 标题和开场承诺的结果，是否能用真实资料、实际操作或明确方法兑现？
5. **反例检验：** 哪些场景不适合这套方案？例如资料无授权、音画质量差、内容不完整、业务规则频繁变化、专业判断没有经过确认。

### 3.3 事实、推断与未知必须分开

- **事实：** 有原始材料、明确对象和可追溯来源。
- **推断：** 基于事实作出的解释或方案判断，不能写成已经发生的结果。
- **未知：** 缺少素材、授权、数据或独立验证；不得包装成事实。

“可能适合”“可以尝试”“需要先评估”比无证据的“必然提升、自动获客、效率翻倍”更专业。

# 4. 六条精修标准样稿

> **时长口径：** 每条口播正文约234–254个汉字，整体约267–289个可见字符。按正常口语速度，预计约60–85秒。此为编辑估算，不是实测结果；发布前必须由非原稿作者真人朗读并计时，超出60–90秒时再删改。

## 01｜直播回放二次开发

**业务线：** A｜AI视频剪辑  
**目标客户：** 直播商家、品牌运营、MCN机构、企业直播团队  
**主要业务任务：** 让已有直播素材继续承担不同营销任务  
**服务交付：** 直播内容转写与筛选、主题规划、AI辅助剪辑、字幕与版本制作、人工复核。

### 营销入口比较

- 入口A｜数量承诺：“一场直播剪出十条视频”。风险：把数量当价值，未说明每条视频的用途和合格标准。
- 入口B｜资源价值：“直播回放不只是一条录像”。方向成立，但仍需说清如何继续利用。
- 入口C｜具体营销任务：“从直播中筛出卖点、演示和答疑，分别制作不同用途的视频”。**选定C作为正文主线，封面用回放闲置场景引起代入。**

### 封面与发布信息

- **封面主标题：** 直播一结束，回放就闲置？
- **封面副标题：** AI剪出卖点、演示和答疑视频
- **发布标题：** 直播回放怎么二次利用？AI把产品卖点、演示和答疑剪成不同视频
- **0–3秒：** 直播一结束，回放就闲置？
- **3–8秒：** AI先找出卖点、演示和答疑，再剪成不同视频。

### 完整口播稿（约60–85秒）

直播一结束，回放就闲置？AI先找出卖点、演示和答疑，再剪成不同视频。

关键不是把一小时切成十段，而是看每段内容能解决客户哪个问题。先把有授权的原片转写，按主题标出时间点；再筛出信息完整、画面清楚、适合独立表达的片段。

产品特点做成卖点讲解，操作过程做成演示，常见问题做成答疑。接着补上必要的开头、字幕和上下文，剪成对应版本。

AI负责转写、初筛和辅助剪辑，人负责判断内容是否准确、是否值得发布，以及有没有遗漏关键条件。

这样，一场直播才可能从一次播出，变成一组可继续使用的营销内容。你有直播回放，可以先选一段产品演示，评估它适合做哪类视频。

### 自辩自证

- **为什么选这个入口：** “回放闲置”是可识别的内容使用场景；后续用卖点、演示、答疑三种内容类型兑现，不停留在“多剪几条”。
- **为什么客户需要服务：** 价值不只是自动切片，而是判断片段是否完整、适合哪种营销任务、需要补什么上下文，以及最终剪辑和复核。
- **必须展示的证据：** 有授权的直播原片、转写与时间点、筛选出的片段、三类不同成片。
- **反例与边界：** 原片音画质量差、没有独立表达内容、未经授权，或片段脱离上下文会改变原意时，不应强行剪辑。
- **本条真正卖点：** 把直播素材按营销目的重新开发，而不是单纯增加剪辑数量。

## 02｜行业论坛与专家内容再开发

**业务线：** A｜AI视频剪辑  
**目标客户：** 行业协会、论坛主办方、企业市场部、专家团队、培训机构  
**主要业务任务：** 把活动录像中的专业内容转化为可独立传播的主题视频  
**服务交付：** 活动录像筛选、发言转写、观点与案例整理、系列剪辑、专业复核。

### 营销入口比较

- 入口A｜活动宣传：“论坛结束后，如何继续宣传活动”。风险：容易变成普通活动回顾。
- 入口B｜专家价值：“专家的观点值得被更多人看到”。有情绪，但交付方式不够具体。
- 入口C｜内容再开发：“把专家观点、案例和方法拆成独立主题视频”。**选定C，明确区别于活动回顾。**

### 封面与发布信息

- **封面主标题：** 论坛结束，专家内容别沉底
- **封面副标题：** AI剪成观点、案例系列视频
- **发布标题：** 行业论坛录像怎么二次开发？AI剪辑专家观点、案例和答疑
- **0–3秒：** 论坛回顾发完，专家内容就结束了？
- **3–8秒：** AI转写发言，再把观点、案例拆成独立视频。

### 完整口播稿（约60–85秒）

论坛回顾发完，专家内容就结束了？AI转写发言，再把观点、案例拆成独立视频。

活动回顾记录了现场，但真正值得继续传播的，往往是专家回答了什么问题、给出了什么判断。

先选有授权、音画清晰的发言素材；AI辅助转写并标出观点、案例、方法和答疑。编辑时不要只截一句金句，要保留观点依据和必要上下文。

接着按每个主题重写开场和标题，需要解释的地方配现场PPT、图表或真实画面，再剪成系列短视频。

发布前由主讲人或业务负责人核对专业表述、数据和引用。

这样，活动回顾负责记录现场，系列视频负责把具体知识送到真正需要的人面前。你有论坛或培训录像，可以先选一位讲者的完整发言，评估能拆出哪些独立主题。

### 自辩自证

- **为什么选这个入口：** 不是重复宣传“活动很成功”，而是指出活动回顾与专家知识传播是两种不同交付。
- **为什么客户需要服务：** 专业内容不能只靠自动切片，需要主题编辑、上下文保留、画面补充、系列化组织和专家复核。
- **必须展示的证据：** 完整发言录像、转写稿、主题时间点、观点与案例片段、专家确认后的成片。
- **反例与边界：** 发言没有独立主题、资料无法授权、专家观点依赖大量未提供的背景时，不能仅凭AI摘要制作权威讲解。
- **本条真正卖点：** 将一次性活动内容转化为可独立观看的专业知识视频。

## 03｜专业服务的客户理解视频

**业务线：** B｜AI口播稿视频  
**目标客户：** 咨询公司、专业服务机构、企业服务团队、品牌与技术服务商  
**主要业务任务：** 让潜在客户理解专业服务如何解决自己的问题  
**服务交付：** 客户问题提炼、专业资料转口播、流程图与屏录组织、讲解视频制作、专业审核。

### 营销入口比较

- 入口A｜企业形象：“公司介绍怎么做得更专业”。风险：仍然以企业自身为中心。
- 入口B｜服务清单：“把服务范围做成视频”。风险：客户仍然不知道具体能解决什么。
- 入口C｜客户问题：“客户问你能做什么，你又发公司介绍？”**选定C，以真实咨询问题切入，再展示AI口播视频如何解释处理过程。**

### 封面与发布信息

- **封面主标题：** 公司介绍发了，客户还不懂？
- **封面副标题：** AI口播把专业服务讲清楚
- **发布标题：** 专业服务怎么让客户听懂？用AI口播视频解释流程、资料和案例
- **0–3秒：** 客户问你能做什么，你又发公司介绍？
- **3–8秒：** AI把真实咨询整理成口播稿，再配流程图和案例。

### 完整口播稿（约60–85秒）

客户问你能做什么，你又发公司介绍？AI把真实咨询整理成口播稿，再配流程图和案例。

公司介绍通常列的是资质、团队和服务范围，但客户更想知道：我的问题你怎么处理，需要准备什么，哪些情况还要进一步核实。

先挑一个真实、高频的问题，再从已审核的业务资料中找依据。AI辅助整理口播稿和讲解结构，把专业流程拆成客户听得懂的步骤；再配真人口播或获授权的数字人口播、流程图和真实屏录。

案例必须脱敏并获得授权。最后由专业人员核对结论和适用边界，再制作成一条讲解视频。

客户看到的就不只是“我们能做什么”，而是“我的问题大致会怎样被解决”。你可以先挑一个客户最常问的问题，做成第一条专业讲解视频。

### 自辩自证

- **为什么选这个入口：** 客户的问题比企业自我介绍更接近真实购买任务；正文必须展示“问题—处理步骤—资料要求—边界”。
- **为什么客户需要服务：** 专业服务机构需要有人把业务知识转成客户语言，并组织口播、流程图、屏录和案例；仅生成一段文案不等于完成视频交付。
- **必须展示的证据：** 真实客户问题、已审核的业务资料、口播稿前后版本、流程图、真实屏录、脱敏且获授权的案例。
- **反例与边界：** 如果企业没有稳定的服务流程、专业答案尚未审核，或客户问题涉及个案判断，不应把通用视频包装成确定性解决方案。
- **本条真正卖点：** 把专业服务从“企业自我介绍”转为“客户问题讲解”。

## 04｜企业客服FAQ数字人视频

**业务线：** C｜AI数字人视频  
**目标客户：** 企业负责人、客服负责人、品牌运营、售后服务团队  
**主要业务任务：** 让稳定、重复的标准答案可以反复观看  
**服务交付：** 高频问题归类、标准答案确认、数字人口播视频、真实操作画面、版本管理。

### 营销入口比较

- 入口A｜替代客服：“用数字人代替客服”。风险：夸大能力，容易让用户误解为自动客服系统。
- 入口B｜降低重复工作：“客服不用反复解释”。方向成立，但必须限定为标准问题。
- 入口C｜标准内容复用：“把重复问题做成FAQ视频，特殊问题转人工”。**选定C，既说明价值，也明确能力边界。**

### 封面与发布信息

- **封面主标题：** 客服重复问题，做成FAQ视频
- **封面副标题：** AI数字人讲标准步骤，个案转人工
- **发布标题：** 客服FAQ怎么制作？AI数字人讲标准流程，特殊问题转人工
- **0–3秒：** 同一个问题，客服每天解释多少遍？
- **3–8秒：** AI数字人讲标准步骤，特殊问题转人工。

### 完整口播稿（约60–85秒）

同一个问题，客服每天解释多少遍？AI数字人讲标准步骤，特殊问题转人工。

先说明，这不是能自动处理个案的AI客服，而是预先制作、反复使用的FAQ视频。

适合先做稳定问题：产品怎么安装、资料怎么提交、售后流程怎么走。

把客服记录中的高频问题整理出来，由业务负责人确认答案，再让AI辅助改成简短口播稿。使用获得授权的数字人形象制作讲解，并配真实产品画面和操作步骤。

价格、政策和流程变化时要更新版本；投诉、复杂故障和特殊情况，不能让视频替代人工判断。

它的价值是让标准问题有统一、可重复观看的说明，把客服时间留给需要沟通的个案。先整理客服重复最多的三个问题，判断哪些适合做成FAQ视频。

### 自辩自证

- **为什么选这个入口：** 客服重复解释是具体任务；“标准问题视频化、特殊问题转人工”比“数字人替代客服”准确。
- **为什么客户需要服务：** 企业需要整理问题、确认标准答案、制作数字人口播、匹配真实操作画面，并建立更新机制。
- **必须展示的证据：** 脱敏客服问题、审核后的标准答案、获授权数字人形象、真实产品操作画面、版本日期。
- **反例与边界：** 价格、库存、政策、个性化诊断、投诉和复杂故障等动态或个案问题，不适合只靠静态FAQ视频解决。
- **本条真正卖点：** 让稳定的标准答案有统一的视频说明，不冒充实时AI客服。

## 05｜产品参数转选购与使用讲解视频

**业务线：** B｜AI口播稿视频  
**目标客户：** 电商商家、品牌方、产品运营、外贸企业  
**主要业务任务：** 把产品参数转化为客户能理解、能比较、能使用的信息  
**服务交付：** 产品资料整理、选购问题拆解、口播稿、实拍与图解组织、视频制作、参数核验。

### 营销入口比较

- 入口A｜说明书视频化：“把说明书做成视频”。风险：只是把文字念出来，客户未必更容易理解。
- 入口B｜产品卖点：“用AI突出产品优势”。风险：容易变成空泛广告，甚至夸大功能。
- 入口C｜购买决策：“参数写全了，客户还是不会选？”**选定C，围绕型号差异、适用条件和真实使用方式组织内容。**

### 封面与发布信息

- **封面主标题：** 参数写全了，客户还是不会选？
- **封面副标题：** AI口播配实拍，讲清型号差异
- **发布标题：** 产品说明书怎么做成视频？AI口播+实拍讲清型号差异和使用方法
- **0–3秒：** 参数都写了，客户还是不会选？
- **3–8秒：** AI整理型号差异，配真实商品画面讲清楚。

### 完整口播稿（约60–85秒）

参数都写了，客户还是不会选？AI整理型号差异，配真实商品画面讲清楚。

说明书按参数写，客户却按需求做决定：尺寸合不合适、型号差在哪里、怎么使用、哪些情况不适用。

先把型号、规格、材质、功能和注意事项整理成核对过的产品资料，再让AI辅助拆成选购、对比和使用三个方向的口播稿。

型号对比要讲清差异；使用教程要拍真实操作；注意事项要保留原始说明中的限制。

视频尽量使用真实商品和实拍步骤，不能让AI补造功能或测试结果。最后由产品负责人核对参数和字幕，再制作旁白、图解和成片。

这不是把说明书念一遍，而是把产品信息翻译成客户做决定时需要的信息。先选一款咨询最多的产品，做一条型号对比或使用讲解。

### 自辩自证

- **为什么选这个入口：** 客户不是为了看参数而看视频，而是为了判断产品是否适合自己；因此从选购决策切入。
- **为什么客户需要服务：** 需要产品资料核验、客户问题拆解、口播结构、真实商品拍摄、图解和成片制作，不能只靠AI改写说明书。
- **必须展示的证据：** 原始说明书、型号参数对照、真实商品、实际操作过程、产品负责人审核记录。
- **反例与边界：** 参数不完整、不同型号信息混淆、缺少测试依据时，不得让AI补造功能、效果、性能或比较结论。
- **本条真正卖点：** 将产品资料转化为客户购买前真正需要理解的讲解内容。

## 06｜专家经验转岗位培训视频

**业务线：** B｜AI口播稿视频  
**目标客户：** 企业老板、培训负责人、专家、知识管理人员  
**主要业务任务：** 将经过确认的专家经验转化为可学习、可检索、可更新的岗位知识  
**服务交付：** 授权资料整理、会议转写、知识结构化、专家补充访谈、口播稿与分镜、培训视频制作、版本管理。

### 营销入口比较

- 入口A｜会议录音：“会议录音怎么变成视频”。风险：像普通工具教程，没有说明企业为什么需要。
- 入口B｜专家知识：“把专家经验留下来”。方向成立，但抽象，缺少具体工作场景。
- 入口C｜重复询问：“专家讲过，团队还在反复问？”**选定C，连接专家重复解释与岗位培训的具体任务。**

### 封面与发布信息

- **封面主标题：** 专家讲过，团队还在反复问？
- **封面副标题：** AI提炼经验，做成岗位培训视频
- **发布标题：** 会议录音怎么做成岗位培训视频？AI转写后由专家补齐判断依据
- **0–3秒：** 专家讲过，团队怎么还在反复问？
- **3–8秒：** AI先转写，再由专家补齐判断依据和例外。

### 完整口播稿（约60–85秒）

专家讲过，团队怎么还在反复问？AI先转写，再由专家补齐判断依据和例外。

先注意，录音不等于完整知识。如果专家只说了结论，没有讲为什么、适用什么条件，AI不能替他猜。

第一步，选一段已获授权的会议录音，同时找相关制度、案例或操作文件。AI辅助转写，并把内容整理成问题、判断依据、操作步骤、适用条件和例外情况。

缺少的部分，再安排专家补充确认。资料核实后，才制作口播稿和分镜：流程用图解，操作用真实屏录，案例要脱敏。

成片还要标注审核人和版本，业务变化时及时更新。

这样沉淀的不是一段会议摘要，而是团队可以反复学习的岗位知识。你可以先挑一个经常被重复解释的业务问题，验证它能不能做成培训视频。

### 自辩自证

- **为什么选这个入口：** “反复询问”是具体工作场景，比抽象的“知识资产沉淀”更容易让企业负责人理解。
- **为什么客户需要服务：** 会议转写只是起点；真正困难的是补齐判断依据、适用条件和例外，并由专家审核，再制作成可学习的视频。
- **必须展示的证据：** 授权会议录音、相关制度或案例、转写稿、专家补充记录、审核后的脚本、培训视频和版本记录。
- **反例与边界：** 只有录音而没有相关文件、专家没有讲清判断依据、内容涉及保密或未经授权时，不得直接生成“标准知识”。必要时必须追加专家访谈。
- **本条真正卖点：** 将专家经验转化为经过审核的岗位培训内容，而不是把会议摘要换一种形式播放。

# 6. 发布前的独立验证与验收

## 6.1 事实和素材验证

每条视频至少建立以下核对项：

- 原始素材来源、使用授权和可公开范围；
- 关键事实、产品参数、专家观点或业务结论；
- AI生成内容与真实素材的区分；
- 需要人工确认的专业判断；
- 画面、旁白、字幕与标题是否一致；
- 动态信息是否标注版本或更新时间。

## 6.2 封面盲读

每种主要共同任务建议找5名真实目标用户。

操作方式：

1. 展示带有真实主体和主副标题的封面缩略图约3秒；
2. 隐藏封面；
3. 询问对方：看到了什么？认为讲什么？预计能得到什么？
4. 再询问是否愿意点开，以及原因。

内部筛选参考：

- 至少4人说对主题；
- 至少3人说出与正文一致的具体价值；
- 没有多数人产生严重误解。

这只是小样本内部筛选线，不代表统计显著性，也不是平台官方标准。

## 6.3 前8秒独立测试

不展示封面，只播放前8秒，询问目标用户：

- 这条视频是讲给谁看的？
- 它解决什么问题？
- AI视频具体做了什么？
- 你预计后面会看到什么？

如果用户只回答“讲AI”“介绍一个工具”，却说不出业务任务和具体结果，说明AI视频植入仍然没有打通。

## 6.4 真人朗读和时长测试

- 至少由一名非原稿作者朗读；
- 用实际录音计时，不以模型估算替代；
- 控制在60–90秒；
- 出现拗口、连续术语、需要解释才能听懂、语速不自然时，退回修改；
- 不得为了压缩时长删掉必要条件、证据或风险边界。

## 6.5 发布后的业务验证

不能只看播放量。至少区分：

- **传播信号：** 有效播放、停留、完播、收藏、分享；
- **需求信号：** 评论中出现真实业务问题、主动提交素材、询问服务范围；
- **商业结果：** 合格咨询、报价、成交、复购。

播放量增长不能直接证明客户愿意购买AI视频服务；一次咨询也不能证明内容形成了稳定获客能力。

# 7. V4.1质量评分映射

本文件中的六条样稿目前属于**编辑候选**，未经过独立评审和真实用户测试，因此不预先给出虚构分数。

后续应按以下权重逐条评分，每项评分必须附原文或证据：

| 评分维度 | 权重 | 重点检查 |
|---|---:|---|
| 用户需求与目标受众准确性 | 15 | 是否对应真实共同任务，观看回报是否与用户有关 |
| 主标题、副标题及点击理由 | 15 | 主副是否互补，入口是否具体且可兑现 |
| 黄金开场与3–8秒承接 | 15 | 是否唤醒用户，第二段是否新增信息 |
| 正文故事、方法与价值兑现 | 20 | 是否有过程、方法、证据、结论和边界 |
| 事实证据与可信度 | 10 | 是否有来源、授权和人工复核 |
| 平台原生表达 | 10 | 是否符合平台内容场景和表达习惯 |
| Calling与评论转化 | 10 | 是否只有一个主要行动，下一步是否具体 |
| 真人表达自然度与原创性 | 5 | 是否口语自然、无机械模板和不必要AI腔 |
| **合计** | **100** | |

放行原则：

- 85–100分：硬门禁通过、独立评审无重大分歧，才可列为强候选；
- 75–84分：必要问题修复后，可列为发布候选；
- 70–74分：必须二次打磨；
- 低于70分：退回重写；
- 任一事实、授权、兑现或合规硬门禁失败，不论总分多少都不得放行。

**不得用六条平均分掩盖单条问题，也不得用模型自评替代目标客户理解和真人朗读。**
