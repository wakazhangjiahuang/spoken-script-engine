## 三、标题 7 大公式速查（封面 + 标题共担点击率）

> 标题核心公式：**人群 + 痛点/场景 + 数字 + 结果 + 情绪词**

| # | 公式         | 模板                           | 实战案例                      |
| - | ---------- | ---------------------------- | ------------------------- |
| 1 | **数字型**    | X 个方法 / X 天搞定 / X 元搞定        | 《3 个让笔记阅读量翻 10 倍的标题技巧》    |
| 2 | **痛点直击型**  | 你是不是也……/别再……/为什么你总是……        | 《为什么你发了 100 篇笔记还是没人看？》    |
| 3 | **悬念/反差型** | 原来……/终于明白了/后悔没早知道            | 《用了这个标题套路后，我的阅读量翻了 10 倍》  |
| 4 | **对比型**    | 普通 vs 高手 / 以前 vs 现在 / A vs B | 《月薪 3k 和月薪 3w 的博主，标题差在哪里》 |
| 5 | **身份标签型**  | 写给……/……必看/……专属               | 《干皮姐妹必看的秋冬护肤指南》           |
| 6 | **情绪共鸣型**  | 绝了 / 救命 / 哭了 / 后悔 / 震惊       | 《后悔没早点学会这个标题写法》           |
| 7 | **秘密/内幕型** | XX 内幕 / XX 打死也不告诉你的 / 揭秘     | 《医美行业内幕：这些项目成本不到 100 块》   |

**写作自检 5 问**：

1. 0.5 秒能看懂吗？
2. 关键词在前 15 字吗？
3. 有具体数字吗？
4. 有身份标签吗？
5. 有情绪词或钩子词吗？

**避坑红线**：

- 长度 ≤ 20 字（手机端超过折叠）
- 不用"最/第一/天花板/闭眼入"
- 不用"100% 有效/保证"
- 不用医疗词（治疗/治愈/疗效）

## 四、钩子 8 大公式速查（开头 3 秒决定留存）

> 钩子本质：**让用户在 3 秒内感觉"这说的就是我"**  
> 数据锚点：首句留存率高的笔记，爆款概率是普通笔记的 4.6 倍。

| # | 钩子         | 公式                   | 触发人性    | 模板示例                            |
| - | ---------- | -------------------- | ------- | ------------------------------- |
| 1 | **反常识钩子**  | 大众认知 + 其实/竟然 + 反常识真相 | 慕强 / 焦虑 | 「你每天敷面膜其实是在毁脸，皮肤科医生从不让人天天敷。」    |
| 2 | **数字承诺钩子** | 时间/数量 + 效果承诺 + 方法预告  | 懒惰 / 贪婪 | 「3 天让痘痘瘪下去的方法，我试了 2 年才敢发。」      |
| 3 | **痛点场景钩子** | 高发痛点场景 + 情绪词 + 转机预告  | 损失规避    | 「你是不是也受够了每天加班到 10 点，工资却只够交房租？」  |
| 4 | **身份标签钩子** | 精准人群 + 圈层共鸣 + 利益预告   | 联盟 / 圈内 | 「INFP 的人，表面随和，内心其实早就把你判了死刑。」    |
| 5 | **悬念故事钩子** | 异常结果 + 因为/直到 + 转折线索  | 八卦 / 好奇 | 「删了暧昧对象后，他突然发来这句话…」             |
| 6 | **利益钩子**   | 时间成本 + 诱人回报          | 贪婪 / 懒惰 | 「花 3 分钟学这招，小个子也能穿出 1 米 8 大长腿。」  |
| 7 | **警告避坑钩子** | 惨痛经历 + 经验教训          | 损失规避    | 「我花了 2 万块买的心理咨询课，发现全是百度能搜到的东西。」 |
| 8 | **内幕揭秘钩子** | 行业 + 绝不会告诉 + 真相      | 傲慢 / 圈内 | 「健身教练绝不会告诉你的"偷懒减肥法"。」           |

**反向输出（高级）**：颠覆常识 → 制造冲突 → 想点开看为什么

- 公式：你以为 X？其实 X
- 案例：「你以为多喝水能减肥？其实喝错时间反而会水肿。」

## 六、正文结构 3 大模板

### 6.1 黄金三段式（最常用 / 通用）

```
【开头 20%】痛点引入（前 80 字埋人群+场景+主关键词）
   "你是不是也……" → 引发共鸣 → 引出方案

【中间 60%】干货输出（分点 + 图 + 案例）
   ▪️ 要点一
   ▪️ 要点二
   ▪️ 要点三
   （每段 ≤ 3 行，emoji 1-2 个/100 字）

【结尾 20%】互动引导（提问 + 收藏 + 关注）
   "你们做 X 最卡在哪？评论区告诉我。"
```

### 6.2 SCQA 故事式（卖货 / 种草首选）

| 段        | 作用     | 示例                         |
| -------- | ------ | -------------------------- |
| **S 情景** | 建立认同背景 | "做小红书 3 个月没起色——90% 运营者都点头" |
| **C 冲突** | 打破平衡   | "同行却爆单了——凭什么别人行你不行？"       |
| **Q 问题** | 锁定注意力  | "为什么？" → 用户开始主动思考          |
| **A 答案** | 给出方案   | "缺爆款选题库" → 你的产品即答案         |

**变体 ASC（开门见山型）**：干货文首选，答案先行 → 情境 → 冲突 → 问题

### 6.3 70-30 避害趋利式（卖货文案黄金配比）

- **前 70% 避害**：戳痛点 / 讲风险 / 量化损失（"错过这 3 个细节，你的 X 就白做了"）
- **后 30% 趋利**：给方案 / 画愿景 / 兑现价值（"按这套流程，你也能 X"）

**底层原理**：情绪启动需要铺垫。上来就给方案，痛点未激活；全程恐吓，用户焦虑瘫痪。

### 6.4 正文排版硬规则（332 法则）

| 项     | 标准                                    |
| ----- | ------------------------------------- |
| 段长    | 每段 ≤ 3 行（约 40-60 字）                   |
| 段间距   | 空一行                                   |
| 重点处理  | 加粗或换色（红/蓝），价格/天数/效果用色块高亮              |
| emoji | 每 100 字 1-2 个，≤ 5 种/篇                 |
| 列表标记  | 1️⃣2️⃣3️⃣ 步骤 / ✅❌ 对比 / 👉 引导动作        |
| 首行    | 不空格不缩进（会被判机器号）                        |
| 字号    | 标题 18-22pt / 小标题 16-18pt / 正文 14-16pt |

## 七、跨人性类型实战模板（直接套用）

### 模板 A：懒惰 + 损失规避（最广谱爆款公式）

**适用**：干货、教程、清单  
**标题**：《X 天 X 个方法，让 X 的人也能 X（不用 X）》  
**钩子**：「你是不是也 X 到崩溃？直到我试了这 X 招…」  
**封面**：白底 + 大字 + 步骤图  
**正文**：3 段式 → 步骤 1/2/3 → 总结清单 → 收藏引导

### 模板 B：八卦 + 害怕（高互动模板）

**适用**：避坑、测评、维权  
**标题**：《在 XX 发现了 X，要不要 X？X 个 X 套路千万别 X》  
**钩子**：「我花了 X 块买的教训，希望你别犯同样的错」  
**封面**：真人表情 + 红叉 + 大字  
**正文**：故事 → 证据 → 解决路径 → 评论区求助


### 模板 C：傲慢 + 联盟（人设向模板）

**适用**：高端人群、IP、设计师、行业专家  
**标题**：《写给 X 的 X 指南 / X% 的人才懂的 X》  
**钩子**：「懂的人自然懂，不解释」  
**封面**：黑金配色 + 留白 + 高级感  
**正文**：圈层共鸣 → 暗语 → 圈内福利 → 引导关注

### 模板 D：贪婪 + 稀缺（强转化模板）

**适用**：福利、拼团、限时  
**标题**：《仅剩 X 份！价值 X 的 X，今天 0 元领》  
**钩子**：「错过恢复原价 X」  
**封面**：红色 + 倒计时 + 大字  
**正文**：价值 → 限时 → 紧迫 → CTA（评论扣 1 / 私信关键词）

### 模板 E：从众 + 嫉妒（流量爆破模板）

**适用**：爆款盘点、同款、慕强  
**标题**：《X 万人都 X 的 X，我试了 X 个月效果 X》  
**钩子**：「凭什么别人 X 而你 X？」  
**封面**：排行截图 + 数字堆叠 + 对比图  
**正文**：别人 → 你 → 差距 → 方法 → 收藏
