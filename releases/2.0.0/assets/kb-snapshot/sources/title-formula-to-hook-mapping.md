# 《小红书爆款标题公式库 v2》→ 口播黄金三秒映射

## 原始资料定位
- 名称：《小红书爆款标题公式库 v2》（用户提供原始文件：xhs_ai_title_formula_knowledge_v2(1).txt）
- 数量：225条标题公式。
- 分类：15类标题策略——人群定位、数字清单、痛点、悬念、反常识、成本收益、教程、测评、案例、种草销售、趋势、心理动机、客户视角、SEO、互动收藏。
- 角色：上游标题/封面策略素材库；不是口播开场句库、不是平台算法规则、也不是效果数据。

## 正确使用链路
225条标题公式 → 选择本条视频相关策略 → 提取心理机制与用户动机 → 映射20类口播开场逻辑 → 改成自然口语 → 配套首帧/动作/素材 → 核对正文兑现。

标题公式提供的是“从什么角度吸引注意”的思路。口播开场还必须适合说出口、符合创作者声音、能被画面支持，并且能在正文中兑现。标题不需要逐字转成口播句。

## 公式转换规则
1. 不按225条逐条硬改写；先根据本条受众、场景和漏斗阶段筛选少量候选。
2. 把标题里的书面词、夸张词和命令式表达改成创作者自然会说的话。
3. 每个候选都要说明：用户为什么停留、这件事与他有什么关系、正文如何兑现。
4. 同一条视频的标题、首句、首帧和正文必须承诺同一件事。
5. 一条稿件优先选一个主要心理机制；备选开场必须是不同机制，不是同义句。
6. 标题公式的数量不能被当成有效钩子数量或成功率证据。

## 去模板的第二道校验
转换完成后，按 shared/human-voice.md 进行朗读测试和盖稿复述；若句子虽然符合某个标题公式，却不像创作者会说的话，就重新组织表达。不得为了“更自然”添加假经历或虚构具体细节。

## 效果状态
225条原始公式属于素材知识。20类口播开场属于设计方法。两者均不代表经过真实账号A/B测试的有效率；效果状态保持 unknown，需要使用账号后台数据验证。
