# 创作者声音档案｜Voice Profile

## 目标
把用户真实的表达习惯带入口播稿，不替用户发明人设。档案是可修订的工作假设，不是永久人格标签。

## 资料来源
优先使用用户本轮提供的本人作品、逐字稿、语音转写、工作记录和明确的口吻指令。只在样本足够时总结稳定特征。引用其他博主或达人时，只提取结构、镜头或论证方法，不仿写其独特表达。

## 记录维度
- 语气：正式/自然/克制/热情/幽默/锋利
- 句式：短句密度、长句使用、停顿习惯
- 词汇：常用词、专业术语、禁用词、行业表达
- 叙述：第一人称、团队视角、案例、过程、观点
- 情绪：表达强度、反问、感叹和幽默尺度
- 受众关系：同行交流、客户解释、经验分享、教学说明
- 镜头表达：对镜讲述、现场演示、屏幕录制、旁白
- 结尾习惯：问题征集、观点判断、咨询承接、自然收束

## 当前已确认的创作方向
- 真实创业团队和实际开发视角；
- 用具体项目、业务场景、开发过程、方案取舍和可展示结果说明能力；
- 不默认扮演专家或培训讲师；
- 专业表达保留准确性，同时翻译成客户听得懂的业务语言。

以上方向只在与当前内容相关时使用；用户本轮的新要求优先。

## 没有声音样本时
采用“自然、直接、清楚、不过度热情”的中性口吻。不得擅自加入：
- “我做了十年/我们服务过上百家”；
- “上周一个客户/我朋友/有个用户”；
- 未经证实的个人情绪、生活细节、团队经历；
- 为了显得亲切而添加的“兄弟们/家人们/说实话”。

## 交付前
用本轮真实样本对照：是否保留其专业词、句长习惯、表达尺度和判断方式？如果不像，先改表达，不改事实。若只有一个样本，不要据此强行固化全套人设。
