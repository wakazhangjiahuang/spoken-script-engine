# 唯一正式XLSX合同 v2.0
依据用户确认的v4.0五表样例。所选平台数量P对应P+2张表；三平台5表，单平台3表；篇数按任务，不硬编码3或6。

1. 00使用总览：最短使用说明、稿件索引/内链、编辑与发布状态、六项分项分、待拍/试读/规则缺口、拍摄准备。禁止理论和大篇质量说明。
2. 每个平台一表：ID、内容任务、主要受众、封面主/副标题、0–3秒、3–8秒、正文、Calling、画面顺序、发布文案、关键词、时长状态、字数、六项编辑分、完整可朗读稿。正文不含制作标签；F–I顺读与P列完整稿必须一致。
3. 拍摄执行卡8列：ID、平台、时间建议、段落功能、对应台词、画面/动作、重点字幕、素材状态/真实性/拍摄提示。筛选ID即可顺序拍摄，不能只写“展示作品”。

冻结表头和ID；一稿一色；自动换行、足够行高、筛选、总览内链。大段背景不重复。时间轴从0累计，与段时一致；文本估速须标估计；真人试读才标实读。
