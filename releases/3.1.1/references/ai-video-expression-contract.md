# AI视频口播表达合同｜Expression Contract 1.0

## 表达链
封面主标题 → 封面副标题 → 0–3秒开场 → 3–8秒承接/悬念 → 正文首段 → 证据与过程 → 核心结论 → Calling → 评论钩子。

每个节点承担不同任务，不允许同义复述。

| 节点 | 观众心理任务 | 必须做到 | 常见失败 |
|---|---|---|---|
| 主标题 | 这和我有什么关系？ | 对准受众问题/结果/选择 | 作者自述、工具堆砌、空泛情绪 |
| 副标题 | 点开后能看到什么？ | 补充方法、范围、证据或场景 | 重复主标题、夸大承诺 |
| 0–3秒 | 值不值得停留？ | 具体问题/冲突/现场/结果 | 复读封面、泛泛开场 |
| 3–8秒 | 为什么继续看？ | 新信息、未解疑问、关键证据预告 | “问问老司机”等空壳 |
| 正文 | 我能学到什么？ | 按问题推进，证据与画面对应 | 功能罗列、技术名词堆叠 |
| Calling | 我下一步做什么？ | 一个明确动作和真实后续 | 评论+私信+关注多重索取 |
| 评论钩子 | 我容易怎么回应？ | 与Calling同目的，问题具体易答 | 机械复制、诱导隐私 |

## 用户视角改写测试
把标题里的主语换成目标用户，读起来是否仍然成立？
- “我们做了一个AI剪辑Skill” → 创作者关心的是“我的口播素材能不能少花时间剪、成片会不会漏重点”。
- “Claude/Codex几分钟剪完视频” → 必须拆分首次配置、素材准备、执行、渲染、返工、验收；没有实测，不可把局部执行时间说成全流程时长。
- “老奶奶也会” → 必须有真实体验者独立操作证据；否则改成“零基础操作流程演示”，不可借人物标签制造假证明。
- “一篇文案秒变视频” → 需要交代素材准备、口播改写、分镜、生成和校对，不可把多步骤隐藏成一键。

## 口语自然度
逐句检查：谁在说、对谁说、在什么场景说、这句话听起来像不像真人现场表达。删除“评论区calling：”“一起聊聊AI落地”“AI真实现每个人都能做IP”等生硬拼接。不要把表格字段名称读出口。

## 标题与正文兑现
标题承诺“几分钟”，正文必须定义计时口径并有计时记录；标题承诺“小白能做”，必须展示小白独立完成的过程；标题承诺“专业成片”，必须展示同一素材的对照与验收标准；标题承诺“企业数字人”，必须讲清适用内容、授权和审核边界。

## 反例库（用于拦截，不可照抄）
- “剪辑师天塌了？”：冲突大于用户利益，且正文实际上讲AI能协助的几项标准工序；除非有岗位影响证据，否则改为任务级表达。
- “AI工程师-打假”：作者/嘉宾身份占据标题，未明确观众能获得的判断。
- “成片如牛来？”、“AI剪辑密码”：语义不清、无法形成稳定观看预期。
- “老奶奶都会”：无真实独立操作证据时属于未经证明的能力承诺。
- “图文笔记天塌了”：制造行业替代焦虑，未说明用户如何复用内容。
- “邪修/零门槛/喝杯咖啡”：夸张词不能代替操作条件、计时和真实结果。
- “评论区calling：AI”：把内部字段名暴露给观众，语言不自然。

## 正例（合成示例，不是实测结果）
主题：AI能帮助剪口播哪些步骤？
主标题：口播剪辑最耗时间的4步，AI能帮你做几步？
副标题：同一条原片，看转写、粗剪、配画面和字幕怎么验收
0–3秒：我把同一条口播原片交给AI处理，先看它能不能把重点找对。
3–8秒：但有一句话不能让它自己删：转折和情绪停顿，必须回听原声。
正文：用同一原片展示转写、粗剪候选、真实画面匹配、字幕与声音；最后对照人工修订记录。
Calling：你最想先减少哪一步重复剪辑？说一个实际场景，我按这个场景做下一次演示。
评论：你现在最花时间的是找重点、删停顿，还是配画面？
说明：此为表达结构示例；真实效果、时间和改动数量必须现场验证。
