# 15项逐稿验收｜v3.6.1

每篇脚本必须逐项记录标准ID、状态、实际引用、证据ID和具体理由。不得以批次平均分放行。

| ID | 环节 | 必须证明 | 主要核验对象 |
|---|---|---|---|
| user_need | 用户需求 | 真实受众、共同任务、用户利益、来源 | brief、source inventory、hook |
| topic_selection | 选题 | ≥3种差异入口、吸引力/证据/兑现/商业价值、否决理由 | marketing_entry_competition |
| cover | 封面 | 主标题吸引、副标题补价值/产品/信息缺口 | cover_main、cover_sub |
| opening_0_3 | 0–3秒 | 身份/利益/反差/悬念与停留理由 | hook台词 |
| bridge_3_8 | 3–8秒 | 新增信息和价值预告，不重复开场 | bridge台词 |
| body_mode | 正文 | 正文组织与内容模式一致，阶段完整 | narrative_map、spoken segments |
| promise_payoff | 爽点兑现 | 标题承诺由正文的判断/过程/输出兑现 | promise_quote、payoff_quote |
| capability_amplification | 能力放大 | 能力主张有演示证据及人机边界；不适用需说明 | production resource、正文 |
| next_level_value | 痒点升维 | 当前收益之后自然连接下一层需求 | closing/CTA quote |
| calling | Calling | 一个动作、一个理由、一个用户回报 | calling对象和口播 |
| evidence | 证据 | 事实/推断/模拟/未知分层，来源可追溯 | claim_evidence、source hashes |
| platform_fit | 平台 | 平台用户任务、原生组织、表达和转化适配 | platform_fit、adapter |
| oral_delivery | 口播 | 真人朗读自然、时长合理、实际可拍 | human_voice_test |
| independent_review | 独立验收 | 非生成者/非同模型换角色，盲审和证据文件有效 | reviewer_attestation |
| outcome_feedback | 效果回流 | 真实发布数据、基准、归因限制、下一步动作 | platform_outcome、feedback analysis |

## 一票否决

- 任何标准FAIL：该稿BLOCKED。
- 原始来源无法定位或SHA不匹配：BLOCKED。
- 独立评审身份/会话/盲审包/证据不成立：BLOCKED。
- 真人试读、盲读、授权或发布数据未完成：VALIDATION_PENDING，不得冒充PASS。
- 任何模型评分、内部自评、CI通过或平均分均不能补偿单项失败。
