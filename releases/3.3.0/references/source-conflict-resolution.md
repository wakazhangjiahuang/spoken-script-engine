# Source Conflict Resolution — 3.3.0

Use this precedence unless the current user explicitly authorizes another source:

1. Current user request, current attachments and explicit field locks.
2. Latest confirmed domain-specific guidance.
3. Original source workbook for locked fields and user-approved facts.
4. Current shared title governance.
5. Current execution sample for structure only.
6. Historical drafts and generic formulas for traceability only.

Rules:
- A complete user-approved benchmark is not a draft to repair.
- A structure sample is not automatically a positive writing example.
- A newer content guide may supersede an older supplementary note.
- AI-video production structure can be reused only as structure; do not transfer AI-video facts or fixed segment counts to another domain.
- When two sources cover different scopes, retain both with explicit scope rather than arbitrarily replacing one.
- Record the conflict, chosen source, rejected interpretation and reason.
