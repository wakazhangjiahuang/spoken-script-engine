# spoken-script-engine 3.3.0 — Runtime Quality Overlay

This release strengthens execution reliability rather than expanding the feature surface.

## Scope
- Pinned GitHub retrieval and source/asset integrity checks.
- Domain isolation and explicit source-conflict resolution.
- Immutable benchmark governance: benchmarks are mechanism references, not scoreable drafts.
- Illustration V2.0 workflow contract: 18 scripts, 3 platforms, 6 sheets, 108 six-part shooting segments, dynamic H3 shots of 4–15 seconds.
- Per-script review, independent reviewer identity, non-compensatory hard gates, export round-trip validation.

## Privacy boundary
This public overlay contains only generic rules, schemas and validators. User-provided Word/XLSX files, client evidence, raw artwork, original lock baselines and private production assets remain in the private plugin package.

## Version pins
The active overlay is pinned by `REPO-REGISTRY.json` at `asset_ref`. The historical AI-video sample source is separately pinned by `manifest_ref`; do not conflate these refs.

CI checks repository contracts only. It does not prove natural speech, audience response, platform reach or commercial outcomes.
