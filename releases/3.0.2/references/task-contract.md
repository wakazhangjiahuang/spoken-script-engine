# 正式交付表格合同 v3

默认P+2张：00使用总览、所选平台各一表、拍摄执行卡。单平台3表、三平台5表；用户只要TXT或局部校正则从其要求。本轮新样例原件是4表，不把它误说成旧10页底座，也不强行增建数据库子表。

平台17列：脚本ID、内容任务、共同任务受众、封面主、封面副、首句、次句、完整正文、Calling、评论（含启用方式）、具体分镜提要/执行卡定位、发布文案、关键词、估时/试读状态、重算字数、可选诊断、连续全文。D/E不引用发布标题；原文锁定不改。完整全文只能由同一segments拼出；不能多一过渡或另换结尾。

执行卡按segment动态行：ID、平台、预计时间、段落功能、对应台词、具体画面/景别机位/动作/切点、字幕焦点、素材ID/位置/状态/真实性/声音留时。可读段落与镜头不是固定六；提要不能代替执行卡，实际原句顺序与全文一致。首镜/关键论据有素材；无素材给真实待办，不伪造结果画面。

总览按ID链接稿件及准备事项，列原件缺口、待拍、试读和平台/账号核验状态；不以生产评分叫发布通过。发布文案、关键词和时间继承同一事实范围；未测不填结果。

导出必须实际回读：列映射、全部ID、分段→全文→执行卡的逐字顺序、评论不混入朗读、封面锁定、字符例外、无公式注入、行高/宽度与跨表定位。实际渲染未看则视觉NOT_RUN；不能以空模板或合成测试代表稿件质量。
