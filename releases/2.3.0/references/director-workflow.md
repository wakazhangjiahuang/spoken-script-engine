# 编导决策与可拍交接

先回答「观众看完能做哪一个判断」，再选呈现形式：对镜解释、实物/手部演示、录屏旁白、过程记录或经授权案例。不能因为主题是工具就默认已有可录屏成果。简单知识分享允许一个固定机位贯穿全片。

## 落笔前

每稿 `director_plan` 写 format、visual_premise（首句配什么可见物）、performance_note（停顿/重音/自然态度）、continuity（屏幕/道具/动作前后状态）、editing_rule（何时切、为什么）、fallback（缺素材仍能拍的替代）及 shoot_order（覆盖全部段落ID，可按机位合拍）。不用「高级感」「快节奏」代替执行动作。剧情冲突来自真实约束，禁止虚构拒单、客户吵架、紧急电话和心理活动。

每段的 `shot` 写 framing（如中近景/屏幕局部）、camera（如固定手机/录屏）、action（先做什么再指什么）、material_id（brief.production_resources 中ID或 NONE）、edit_cue（切点和信息理由）、sound（人声/同期声/安静，音乐可选）、subtitle_focus（最多一个核心信息，可留空）、silent_hold_seconds（不能和口播同时完成的观看/操作秒数）。`visual` 是最终给拍摄者的一句指令，须与 shot 一致。素材状态从资源表读取：available/planned/unavailable；未完成演示应写计划拍摄，并提供可用替代，不能变成已经证明效果的画面。

## 四次核对

1. 静音看：画面是否能让观众知道在解决什么问题？抽象知识没有实物可用时，允许清楚的一行字幕，不强加B-roll。
2. 只听声：去掉画面后主张、条件、因果是否仍然正确？字幕不能偷偷替台词增加数据和承诺。
3. 对齐读：开头约前三秒建立关联；操作/看图留实际时间。时长=台词估读+非重叠静默，不统一每5秒切镜。
4. 按资源试拍：一人手机能否拍完？镜头衔接、手势、屏幕状态一致？无新人物、地点和设备的依赖？缺资源先改方案。

## 最低可交付

首镜明确、每段有信息目的、关键主张有来源/演示、动作和台词配合、结尾单一行动；时间连续；台词没有镜头指令；拍摄顺序与应急替代齐全。I列给景别/机位/动作/素材与剪辑点，J列给字幕，M列给声音、表演、连续性、拍摄顺序和替代方案。不是生成成片，也不声称替代现场导演。
