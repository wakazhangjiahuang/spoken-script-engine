# V4.1 Decision Gateway｜Jev/Laya式结构化决策

## 角色
- Rule Engine：字段、Schema、ID、锁定字段、证据引用、重复和一票否决；不评判创意吸引力。
- Fast Screen（Laya-like）：全量初筛、异常识别、相似角度、低置信度和候选排序。
- Deep Review（Jev-like）：营销入口竞争、语义兑现、反例检验、正反论证、平台适配和方案裁决。
- Generator：只依据已批准Topic和Expression Contract生产。
- Independent Critic / Human：从目标用户角度挑错，核事实、自然表达、商业边界和最终版本。
- Decision Policy：综合硬规则、证据、评分、置信度、意见冲突和人工复核决定通过、返工、升级或淘汰。

## 模型身份与独立性
Jev/Laya是能力角色，不代表本插件已经连接这两个模型。模型名称、提供方和ID按实际可用配置填写。多个角色若由同一个模型完成，`independence_level=same_model_role`；同一模型的不同提示词/不同轮次不算独立模型验证。`separate_model`或`human`才可标为外部独立审查。未执行的角色必须是`NOT_RUN`，不能编造结果。

## 决策记录（不输出隐藏思维链）
每个关键节点保存：候选方案、选择理由、主要反对意见、反例/证据、置信度、未决风险、最终裁决、需要修复的字段。有限轮次修复后仍未达到硬门禁或最低分，拒绝放行。

## 路由
Rule Engine → Fast Screen → Generator → Deep Review → Independent Critic/Human → Decision Policy。事实风险、低置信度、评审冲突、锁定字段冲突和重大商业承诺升级人工。Fast/Deep角色未实际运行时不得标PASS。
