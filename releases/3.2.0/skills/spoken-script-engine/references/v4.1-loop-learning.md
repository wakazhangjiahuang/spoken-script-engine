# V4.1 Loop Learning｜失败归因、最小修复、回归与回滚

1. 捕获：保存原始请求、原始输出、版本、失败字段、用户修改原话和Failure_ID。
2. 归因：需求/受众、营销入口、标题、副标题、开场承接、正文兑现、证据、平台、真人表达、路由、工具、Schema、导出或版本。
3. 最小修复：只改根因模块，记录变更、预期改善和潜在副作用。
4. 回归：正向样例、负向样例、边界样例、失败样例和旧成功案例。修复目标必须通过，未改能力不能退化。
5. 对照：同任务同输入比较旧版/新版；独立评分、盲读、真人朗读或发布实测按任务风险选用。
6. 资产状态：candidate → 人工确认 → accepted；未验证结果不进入正向标准库。负向样例保留原始失败和修复说明。
7. 发布：版本、变更记录、测试结果、回滚点。失败时回滚，不让旧版/过期知识污染默认检索。

一次高播放、点赞或单个用户偏好不能自动改写规则；真实反馈必须说明样本、条件、目标指标和因果限制。Loop不自动把模型输出写入全局知识库。
