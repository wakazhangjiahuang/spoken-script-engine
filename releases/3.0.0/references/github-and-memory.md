# 当前知识版本与回流

唯一活动版本为3.0.0，入口由assets/connection-config.json和仓库REPO-REGISTRY.json固定。解析engine_ref_policy=registry_commit获取代码；asset_ref固定完整知识提交。核Manifest、index、release-policy和每文件SHA；实际文件集有未登记旧文件也拒绝。旧根目录资产、旧releases和approved/imported/worked样例已从当前分支/技能/插件活动文件移除，禁止旧快照回退；历史提交仅用于追溯，不可检索生产。

通用方法与九基因独立于插画。当前6原件保存在standards/20261118/originals，来源SHA与1229格逐项去向可查；current-examples仅插画域读取，每平台按共同任务/显式sample ID选择至多2稿，附全文和全部执行段及冲突。15封面来自SRC5，SRC3解释成立/失效条件；其他行业不加载这些原文。没有本行业样例用通用机制加当前事实，不找相近行业硬冒精确命中。

网络不可用可用同版本、校验相符的包内快照；旧版包不可替代。缺知识仅阻断依赖内容，不宣称在线读取。当前官方平台规则与当次账号另核，包内策略不认证算法权重。

记忆按brand_scope隔离、去重、授权后写，反馈采纳、事实修正、编辑偏好与效果数据分开。只有回读确认才标synced；用户修改不等于实发证据。不得把本轮研究四件事写成生产模块。
