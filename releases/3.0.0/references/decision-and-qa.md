# 当前审稿顺序

先用实际封面主副/首镜/两句、正文、Calling、评论与全片分镜回答：观众能否认领对象与内容价值；次句新增什么；承诺在何处兑现；什么判断或资料确有用；一个动作为什么值得做；画面是否实际支持。主副合读，不固定主写利益/副写证据，不强制冲突或赚钱。

内容阶段不看plan、作者解释或分数；先存content_decisions与delivery_checks。fidelity阶段再读原式、基因和来源，核真实迁移及边界。字数、ID、引文、分数都不能替代观众相关性。数值诊断可不使用，低分不是程序代替语义否决的理由。

图鉴/TopN交足可区别项目与依据；身份反转、开发关系、金额、上市和工艺分别核原件。没有当前原件的强事实不继承。评论可备选/禁用，不能为凑列叠加动作。版权/事实校正属于制作记录，除非内容主题需要。

真实目标受众看缩略封面/前八秒复述对象、所得与继续问题；真人计时和新手试拍核实际可执行。发布后台只用同口径实际字段，有分母才算CTR；播放量不代表封面点击。独立模型、真人、用户与后台未测分别写NOT_RUN。
